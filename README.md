# MiniGamesTG

Плагин для **Paper 1.18.2** (Java 17): мини-игры для игроков сервера с интеграцией **Telegram-бота** —
результаты игр приходят игрокам в личные сообщения, игроки следят за своей статистикой,
а бот периодически присылает общую статистику и **топ игроков (лидерборд)** в заданный чат.

## Возможности

- 🎮 **Три типа мини-игр:**
  - **Дуэль (`duel`)** — 1 на 1, победитель определяется автоматически (убийство / смерть / выход соперника);
  - **Реакция (`reaction`)** — через случайную паузу в чат выводится слово, побеждает первый введший его;
  - **Кастомная (`custom`)** — любая своя игра (паркур, прятки, турнир…), организатор вручную вводит призёров.
- 🏆 **Учёт статистики**: игры, победы, очки (победа = 3, участие = 1), винрейт, история игр (хранится в `data.json`).
- 🤖 **Telegram-бот** (long polling, без внешних зависимостей):
  - привязка аккаунта по одноразовому коду (`/start` в Telegram → `/mg tg <код>` в игре);
  - личные уведомления о результатах каждой игры (победа / место / участие);
  - команды бота: `/mystats`, `/last`, `/top`, `/chatid`, `/help`;
  - периодическая рассылка общей статистики и топа-10 в указанный чат (`stats-interval-minutes`).

## Установка

1. Скачайте `MiniGamesTG-1.0.0.jar` (последняя сборка — в ветке `builds`
   или в артефактах GitHub Actions) и положите в папку `plugins/` сервера Paper 1.18.2.
2. Запустите сервер — появится `plugins/MiniGamesTG/config.yml`.
3. Настройте Telegram (см. ниже), затем перезагрузите конфиг командой `/mg reload` (или перезапустите сервер).

## Настройка Telegram

1. В Telegram напишите **@BotFather** → `/newbot` → получите **токен**.
2. В `config.yml` укажите:
   ```yaml
   telegram:
     enabled: true
     bot-token: "1234567890:ABCdef..."   # токен от BotFather
     stats-interval-minutes: 60          # раз в час — общая статистика и топ
   ```
3. **Топ в группу:** добавьте бота в группу, напишите ему `/chatid` — бот ответит ID чата
   (для групп он отрицательный). Впишите его в `report-chat-id`.
   > Важно: чтобы бот видел сообщения в группе, отключите у него Privacy Mode
   > через @BotFather → Bot Settings → Group Privacy → Turn off.
4. Перезагрузите: `/mg reload`.

## Команды (в игре)

| Команда | Описание |
|---|---|
| `/mg create <duel\|reaction\|custom> [название]` | Создать игру (открывается лобби) |
| `/mg join [номер]` | Присоединиться к лобби |
| `/mg leave` | Покинуть лобби |
| `/mg start` | Начать игру (создатель или админ) |
| `/mg end <победитель> [2 место] [3 место]` | Завершить кастомную игру с результатами |
| `/mg cancel` | Отменить игру |
| `/mg list` | Список активных игр |
| `/mg stats [ник]` | Статистика игрока |
| `/mg top [тип]` | Топ-10 игроков (в целом или по типу игры) |
| `/mg tg <код>` | Привязать Telegram-аккаунт |
| `/mg tg off` | Отвязать Telegram |
| `/mg reload` | Перезагрузить конфиг (админ) |

Алиасы команды: `/minigame`, `/minigames`.

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `minigamestg.create` | все | Создание мини-игр |
| `minigamestg.admin` | op | `/mg reload`, отмена/завершение чужих игр |

## Пример игрового цикла

```
Steve:  /mg create duel
Alex:   /mg join 1
Steve:  /mg start            # отсчёт 3-2-1, бой!
# ...Alex побеждает...
# плагин: анонс в чат, +3 очка Alex, +1 Steve,
# обоим приходят уведомления в Telegram (если привязан),
# раз в N минут бот шлёт в группу общую статистику и топ-10.
```

## Сборка из исходников

```bash
mvn package
# готовый jar: target/MiniGamesTG-1.0.0.jar
```

CI (GitHub Actions) собирает плагин при каждом пуше и прогоняет смоук-тест
на настоящем Paper 1.18.2. Свежий jar публикуется в ветке `builds`.
